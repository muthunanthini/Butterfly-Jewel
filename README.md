# 🦋 Butterfly Jewel

## About the Project
Butterfly Jewel is an online jewellery shopping application developed to provide customers with a simple and beautiful shopping experience.

## Features
- User Registration and Login
- Browse Jewellery Collections
- View Product Details
- Add Products to Favourites
- Place Orders
- Manage Customer Orders

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## Database
Database Name: `butterfly_jewel_db`

Database setup file: `database_setup.sql`

## Project Name
**Butterfly Jewel – Jewellery E-Commerce Website**
